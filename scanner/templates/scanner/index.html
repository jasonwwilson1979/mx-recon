NOTICE // All lookups execute server-side through a hardened Python DNS engine (dnspython) — no scan logic is exposed to the browser. Targets are strictly validated (no IP literals or internal names), requests are rate-limited per client IP, and every probe runs inside a query/time budget. Some RBL operators (notably Spamhaus) refuse queries from cloud resolvers — results marked ERR/BLOCKED are inconclusive, not clean. Fix: use the System default resolver, or register Spamhaus DQS and add the *.dq.spamhaus.net zones (see README).
OPERATOR NOTES // Press / anywhere to focus the target field. Enter engages the scan. Blank DKIM selector triggers auto-probing of 18 common selectors. The M-10 inventory captures every answer record observed during the run — filter by type or search. Export produces a machine-readable JSON dossier including the full inventory.
